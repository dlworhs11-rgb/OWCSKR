# 04. 집계 계산

## 선수
- K/D = 처치 / max(죽음,1)  (K/D/A도 같이)
- 10분당 처치/딜/힐 = 값 / 플레이시간(초) * 600
- POTM 횟수 = 경기 result.potm 카운트 (선수 페이지의 potmCount와 대조 검증)
- 역할별(탱/딜/힐) 순위 분리

## 팀
- 경기 승률, 맵 승률, 연속 승/패
- 대회별 최종 순위

## 필터
- 시즌/대회/기간 선택, 한국 대회만 vs 국제 포함
