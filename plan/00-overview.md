# 00. 전체 개요 (OWCSKR)

## 목표
한국 OWCS(과거 시즌 전체 + 한국팀이 나가는 국제대회)를 한 곳에서 보는 공유용 사이트. 이름: **OWCSKR**.

## 확정된 결정
- 벤치마킹: owtics (화면 구성/항목만 참고, 데이터는 받지 않음)
- 데이터: Liquipedia API(공식, 출처 표기) + 공유 시트 + 중계 화면 직접 읽기(선수 스탯). OWTICS/OWTV는 사용하지 않음 (01 문서 참고)
- 세부 스탯(처치/피해/힐): **나중에** (VOD에서 읽기, 검수는 샘플 확인)
- 첫 화면: 지금 라이브 + 최근 결과 + 대회 일정/순위
- 디자인: 나중에 세세하게 (지금은 기능 우선)
- GitHub 아이디 후보: dlworhs11-rgb (확인 필요)
- 범위: 한국 OWCS 전 시즌 + 한국팀 나가는 국제 그랜드파이널 등
